================================================================================
                    SISTEMA DE INVENTARIO PROFESIONAL
                            GUÍA RÁPIDA DE INICIO
================================================================================

¡Bienvenido al Sistema de Inventario Profesional!

Este software te ayudará a gestionar tu inventario de manera eficiente con
detección automática de stock bajo y notificaciones inteligentes.

================================================================================
INICIO RÁPIDO (3 pasos)
================================================================================

1. CARGAR DATOS DE PRUEBA (Opcional - Recomendado para primera vez)

   Ejecuta:
   > python cargar_datos_prueba.py

   Esto creará productos y proveedores de ejemplo para que veas el sistema
   funcionando inmediatamente.

2. INICIAR LA APLICACIÓN

   Opción A - Doble clic en:
   > INICIAR.bat

   Opción B - Desde la terminal:
   > python main.py

3. ¡LISTO! El sistema está corriendo

================================================================================
PRIMEROS PASOS EN LA APLICACIÓN
================================================================================

DASHBOARD
---------
Aquí verás un resumen de tu inventario:
- Total de productos
- Productos con stock bajo (en rojo)
- Número de proveedores
- Valor total del inventario

PRODUCTOS
---------
1. Clic en "Nuevo Producto" para agregar productos
2. Completa el formulario:
   - Código (único para cada producto)
   - Nombre
   - Precios de compra y venta
   - Stock actual, mínimo y máximo
   - Proveedor asociado

3. Usa "Entrada Stock" cuando recibas mercancía
4. Usa "Salida Stock" cuando vendas o uses productos

PROVEEDORES
-----------
1. Antes de crear productos, registra tus proveedores
2. Clic en "Nuevo Proveedor"
3. Ingresa datos de contacto
4. Usa "Ver Productos" para ver qué productos te suministra cada proveedor

ALERTAS
-------
- El botón 🔔 en la parte superior muestra alertas pendientes
- Recibirás notificaciones automáticas cuando el stock esté bajo
- El sistema verifica cada 5 minutos

REPORTES
--------
Genera tres tipos de reportes:
1. Reporte de Stock: Estado de todos los productos
2. Reporte de Valor: Cuánto vale tu inventario
3. Reporte de Movimientos: Historial de entradas/salidas

================================================================================
CREAR EJECUTABLE (.exe)
================================================================================

Para distribuir la aplicación sin necesitar Python:

1. Ejecuta:
   > python crear_ejecutable.py

2. Espera a que termine (puede tardar varios minutos)

3. El ejecutable estará en:
   > dist/SistemaInventario/SistemaInventario.exe

4. Copia toda la carpeta "SistemaInventario" a cualquier PC Windows
   y ejecuta el .exe (no requiere Python instalado)

================================================================================
RESOLUCIÓN DE PROBLEMAS
================================================================================

PROBLEMA: "Python no se reconoce como comando"
SOLUCIÓN: Instala Python desde python.org y marca "Add to PATH"

PROBLEMA: No aparecen las alertas
SOLUCIÓN: Las alertas se verifican cada 5 minutos. Puedes forzar la
          actualización haciendo clic en el botón "Actualizar" del Dashboard

PROBLEMA: Error al crear producto duplicado
SOLUCIÓN: Cada producto debe tener un código único. Cambia el código.

PROBLEMA: No se puede eliminar un proveedor
SOLUCIÓN: El sistema marca como "inactivo" en lugar de eliminar permanentemente
          para preservar el historial
